Boussole Budget Vert 1.2 - dossier portable

Pour ouvrir l'application, double-cliquez sur le fichier index.html.

Ce dossier peut être déplacé, copié ou renommé. Les fichiers doivent simplement rester ensemble dans le même dossier, notamment :
- index.html
- le dossier assets
- NOM_DE_COLLECTIVITE-BBV-modele.ods

Le dossier peut aussi être déposé dans n'importe quel sous-dossier d'un site web statique : les chemins utilisés par l'application sont relatifs.
